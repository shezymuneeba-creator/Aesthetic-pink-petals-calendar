# 🌸 Pink Petals Calendar

A cute pastel-pink calendar made with **Python & Tkinter** 💗

## ✨ Features

* 📅 Monthly calendar
* ◀️ Previous & next month navigation
* 🌸 Falling pink petals animation
* 📝 Add your plans
* 💕 View all saved plans
* ♡ Planned dates are marked on the calendar
* 🎀 Cute pastel-pink interface

## 🛠️ Built With

* Python
* Tkinter

## ▶️ How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project in VS Code or another Python editor.
4. Run the Python file.

## 💗 About

Pink Petals was created as a fun beginner-friendly Python project to combine coding with a cute, aesthetic design.
